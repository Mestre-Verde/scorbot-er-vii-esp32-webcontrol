1) envia o request e espera por uma confirmação para enviar o file.(WIFI para ESP)
request:
   - ApEnD\r;
   - ReCeIvE\r;
   - ReCeIvE programName\r;

2) esvazia o buffer interno TX FIFO que vai para o controlador (esp)

3) manda  backspace "08" para a mainframe e esta responde com "08 20 08" enquanto tiver caracteres no seu buffer.(ESP para mainframe)

4) envia o byte "06" (ACK) para o PC e este começa a enviar o ficheiro byte a byte em que o final de cada linha deve conter "\r\n". (ESP para PC)

5) enquanto o PC envia o ficheiro o ESP verifica o buffer interno a ver se está quase cheio. (esp)
    Se estiver quase cheio, envia XOFF para o PC, Quando estiver vazio manda XON.

6) Quando o ficheiro chega ao fim (chega na linha "end\r\n"), espera que o TX FIFO do ESP esvazie. Envia-se o byte "04" (End of Transmission).

7) Depois de enviar o "04", o ESP sai do modo de transferência e fica novamente disponível para receber um novo request.
